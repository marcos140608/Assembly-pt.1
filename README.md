# Assembly - PT.1

Repositório com exercícios de Assembly, organizados como material de estudo e prática. Os exercícios abaixo foram passados por Leandro Collevati.

## Exercícios

- `soma.asm` — exercício de soma.
- `AB.asm` — exercício envolvendo valores A e B.
- `AREA.asm` — cálculo de área.
- `areatrapezio.asm` — cálculo da área de um trapézio.
- `camisas.asm` — problema relacionado ao cálculo de camisas.
- `contagem por intervalos` — contagem por intervalos.
- `divisão.asm` — operação de divisão.
- `hipotenusa.asm` — cálculo da hipotenusa.
- `menor/` — exercício para identificar o menor valor.
- `resto.asm` — cálculo do resto da divisão.
- `salario.asm` — cálculo de salário.
- `triplo` — exercício para calcular o triplo de um valor.

## Objetivo

Praticar lógica de programação e estruturas básicas em linguagem Assembly, com foco em resolução de problemas matemáticos e lógicos.

## Como usar

1. Abra qualquer arquivo `.asm`.
2. Compile e execute conforme a ferramenta/assembler disponível.
3. Ajuste entradas e teste diferentes valores para validar a lógica.

## Estrutura do repositório

- Arquivos `.asm` com exercícios prontos
- Exercícios organizados por tema e operação
- Material de estudo para revisão de lógica em Assembly
